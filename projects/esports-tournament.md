# Esports Tournament

## Summary

Esports Tournament is a full-stack game tournament management project.

### Backend
- Spring Boot Java application in `backend/`
- Uses Spring Data JPA and MySQL connector
- Target Java 21 runtime

### Frontend
- Vite + React application in `frontend/`
- Uses Axios for API calls and Tailwind for styling

### Notes
- Already pushed to GitHub at `https://github.com/utsav-a11y/esports-tournament`
